Implementation requirements

  • Render user-provided values as text nodes or through a sanitising template layer. Never build HTML strings from input. Ship a strict Content Security Policy.
  • Mint client tokens and keys server-side with a CSPRNG, store only a hash, show the secret once and scope it to one client.
  • Replace the prototype's browser storage with the API. Simulated operations here map to real endpoints and must surface their failures the same way.
